# Apple 库存监控 · Apple Stock Watch

给 AI Agent 用的 Skill：替你盯 Apple Store 中国大陆门店的到店取货库存，从没货变成有货时，把消息推到你的 iPhone 上。

适合新机首发没抢到、想等门店补货的人。只查询和提醒，不加购、不下单。

## 它做什么

- 你说一句话，Agent 一步步问你城市、机型、容量、颜色、怎么收通知，全部给选项。
- 配好后在你的电脑上约每分钟检查一次。大连恒隆的 iPhone Duo 使用共享缓存，无需服务器账号、代理或密钥；其他范围仍使用原官网直查。
- 某家店有货了，手机立刻收到通知，点开直接进购买页。
- 查不到数据时会如实告诉你“查不到”，不会当成“没货”。
- 配好后会让 Agent 设一个每小时的巡检：监控进程是否还在跑、数据是否还在更新、通知有没有报错。出问题会自动拉起或提醒你。

## 安装

需要一个装在电脑上、能运行本地命令的 AI Agent（如 WorkBuddy、Codex、Claude Code），以及一台开着的电脑。目前在 Codex 上完整实测过；其他同类 Agent 用的是同一种 Skill 格式。

对你的 Agent 说：

> 请安装这个 Skill：https://github.com/qwbwj3/apple-stock-watch

也可以自己下载本仓库，把包含 `SKILL.md` 的整个文件夹命名为 `apple-stock-watch`，放进 Agent 的 Skill 目录。

电脑上需要 Python 3.9 或更高版本，不用装别的东西。

## 使用

对 Agent 说：

> 用 apple-stock-watch 帮我盯 iPhone Duo

它会依次问你：

1. 在哪个城市取货
2. 要哪个机型
3. 要哪个容量、哪个颜色（可以多选）
4. 手机怎么收通知

一句话里说清楚的它不会再问，比如：

> 用 apple-stock-watch 帮我盯深圳的 iPhone Duo 256G 星光白色

之后可以随时说“现在怎么样”“马上查一次”“换个颜色”“别盯了”。

## 共享库存服务

当前仅覆盖 **大连恒隆广场 · iPhone Duo 全颜色、全容量**，可选其中任意配置。任何安装者都可通过只读 HTTPS 获取同一份缓存；不需要登录 Hanye 的服务器，不提供也不索要 SSH 密钥。

初始化会自动为支持范围选择共享缓存，也可以明确指定：

```bash
python3 scripts/apple_stock.py init --source cache --city 大连 --store R609 --family iphone-duo
```

需要特定颜色/容量时照常添加 `--color`、`--capacity`。手机通知仍按下文配置 Bark，地址只留在自己的电脑上。

- **读取不会加速服务器查苹果。** 服务器单独更新，普通客户端只读取已生成的公开库存文件。
- **区分读取与查询时间。** 客户端约每 60 秒读取；服务器实际查询存在抖动或退避，以显示的库存查询时间为准，不承诺每分钟都成功刷新。
- **失败不会变无货。** 库存超过 120 秒、公共文件心跳超过 45 秒、未知、限流或网络错误，都显示查不到，不自动回退密集直查。
- **其他范围未共享。** 全国门店/其他机型仍使用原功能直接查询官网，不代表全国共享服务已验证。`--source direct` 可明确选直查。
- **老配置不自动迁移。** 如需切换已保存的大连 Duo 配置，先停止监控，再按原城市/颜色/容量重新初始化并选择 `--source cache`，测试通知后重启。

本服务可能限流或暂停，不承诺可用性或抢购成功。[安全与隐私说明](SECURITY.md)。

## 手机通知：Bark

Bark 是 iPhone 上一个免费的小工具，作用是让电脑上的程序能给你的手机发通知，不用注册账号。

1. 在 App Store 搜 Bark，安装，打开，允许通知。
2. 首页有一个 `https://api.day.app/` 开头的地址，点“复制”，在 Agent 问你的时候发给它。

这个地址相当于一把钥匙，拿到它的人能给你的手机发通知。只发给你自己的 Agent，不要发到公开的地方。

## 要知道的几件事

- **电脑得开着。** 监控在你自己的电脑上跑，关机、合盖、断网都会停。macOS 上会自动阻止睡眠。
- **只盯门店到店取货。** 你所在的城市要有 Apple Store，或者你愿意去邻近城市取。不覆盖线上送货的库存。
- **只提醒，不下单。** 自动下单违反苹果的购买条款，订单可能被取消，这个 Skill 不做。
- **查询频率是克制的。** 默认每 60 秒一次，最低 30 秒。查得太密会被苹果官网临时拦截十几分钟；被拦后它会自己停 15 分钟再查。
- **后台运行支持 macOS 和 Linux。** Windows 上需要开着一个终端窗口前台运行。
- 新机开售前状态显示“未开放”，开售后自动变成有货或无货，不用重新配置。
